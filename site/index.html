Web3 与 DID：给普通人的入门课

这门课想回答一个很朴素的问题：当越来越多的账号、资产和凭证搬到网上，「你是谁」这件事该由谁来证明？

Web3 讨论的是网络的所有权和协作方式，DID（去中心化标识符）讨论的是身份由谁签发、由谁保管。两者经常一起出现，但并不是同一件事。

这里不会要求你先懂密码学，也不会推荐任何投资标的。你只需要带着日常使用互联网的经验，按顺序读完几篇短文即可。

读完你应当能分辨常见的宣传话术，知道一项方案到底解决了什么问题、又引入了什么新的信任假设。

学习路径

建议按下面的顺序阅读，每一篇都建立在前一篇的概念之上。

  1. 什么是 Web3：先弄清「去中心化」到底指什么，以及它不指什么。
  2. 什么是 DID：认识一种不依赖单一平台的身份标识。
  3. Web3 与 DID 的关系：看看两者在真实场景里如何配合。
  4. 术语表：随时回查文中出现的名词，不必强记。
